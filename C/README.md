# Rudimentary C — Ordered Learning Path

This repository is organized from foundational C concepts to more advanced topics.
All topic folders use numeric prefixes so they appear in the intended study order.

## Recommended order

1. **Division Operations in C** — integer division, floating-point division, casting, and remainders.
2. **Prefix and Postfix Increment** — the behavioral difference between `++i` and `i++`.
3. **Standard Library and Modules** — headers, library functions, and code organization.
4. **Checking Perfect Square Numbers** — using `<math.h>`, `sqrt()`, and safe checks.
5. **Variable-Length Arrays** — runtime-sized arrays, restrictions, and alternatives.
6. **String Functions** — common string operations, followed by `strcpy()` and `strdup()`.
7. **Handling Apostrophes in Text** — reading and parsing text that contains punctuation.
8. **Passing Arrays and Pointers** — modifying array contents and changing pointer values.
9. **Passing Dynamic 2D Arrays** — jagged arrays, row pointers, and column-size metadata.
10. **Pointers to Structs** — single pointers, double pointers, and arrays of struct pointers.
11. **errno and Error Handling** — detecting and reporting library and system-call errors.
12. **qsort Function** — generic sorting, comparison callbacks, and typed examples.
13. **Time Complexity of Lists of Lists** — analyzing nested linked-data structures.

## Repository conventions

- Top-level topics use two-digit numeric prefixes: `01`, `02`, ..., `13`.
- Subtopics and example groups are numbered in the same way.
- Each topic's main explanation is stored in `README.md`.
- Example source files remain beside the explanation that introduces them.
