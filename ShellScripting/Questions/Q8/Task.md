# Bash Exercise — Count the Number of Words in Each Line

## Problem

Write a Bash script that receives the path of a text file as its first command-line argument.

The file contains multiple lines, and the words in each line are separated by spaces.

The script must:

1. Read the file **line by line**.
2. For each line, count how many words it contains.
3. Print the number of words found in that line.

## Example Input

Suppose `file.txt` contains:

```text
one two three
hello world
this is a longer line
```

## Expected Output

```text
3
2
5
```
